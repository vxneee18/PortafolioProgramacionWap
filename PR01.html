01. Configuración de Entorno y Descubrimiento

Fundamento Teórico: La arquitectura de red virtual segmentada (Red NAT) confina el tráfico broadcast y unicast a los nodos autorizados. En capa de enlace de datos (L2), la resolución de direcciones lógicas a direcciones de control de acceso al medio (MAC) se realiza a través de tramas ARP (Address Resolution Protocol), permitiendo identificar hosts activos sin interactuar directamente con la capa de transporte del objetivo.

02. Escaneo y Reconocimiento de Servicios

Fundamento Teórico: El barrido TCP SYN Stealth (-sS) interroga los sockets enviando paquetes con la bandera SYN sin cerrar el saludo de tres vías (3-Way Handshake). Si el receptor responde con SYN/ACK se concluye un estado abierto; si retorna RST/ACK se deduce cerrado. La extracción de banners examina las firmas textuales emitidas por los servicios expuestos.

03. Fuzzing Web y Mapeo de Rutas

Fundamento Teórico: El descubrimiento de contenido analiza códigos de estado HTTP (RFC 7231). Respuestas 200 OK evidencian recursos expuestos; 405 Method Not Allowed indica que la ruta existe pero exige métodos específicos (p. ej. POST en lugar de GET); y 500 Internal Server Error revela fallos en el tratamiento de excepciones internas o control de acceso.

04. Interacción con API REST y Tokens JWT

Fundamento Teórico: Las interfaces RESTful utilizan JSON para intercambiar datos estructurados en el cuerpo de peticiones POST y manejan esquemas de autorización desacoplados mediante JSON Web Tokens (JWT). Un JWT contiene cabecera, payload con identificadores (claims) y una firma criptográfica con la que el servidor valida la legitimidad de la sesión sin consultar bases de datos en cada petición.

Alta de Identidad

curl -i -X POST http://10.0.2.4:8080/registration \

05. Análisis Criptográfico y Conclusiones

Fundamento Teórico: PBKDF2 (Password-Based Key Derivation Function 2) ralentiza intencionalmente el cómputo encadenando HMAC-SHA256 con un valor sal (salt) a través de un número elevado de ciclos (29,000 iteraciones). Este retardo frena los ataques masivos por diccionario en CPUs estándar, exigiendo diccionarios altamente contextualizados o computación paralela en GPUs. 
echo 'patrick:$pbkdf2-sha256$29000$e0/J.V.rVSol5HxPqdW6Nw$FZJVgjNJIw99RIiojrT/gn9xRr9SI/RYn.CGF84rO40' > hash.txt
john --format=pbkdf2-hmac-sha256 --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
Figura 5.1: Registro de tasa (~573 intentos/s) demostrando el retardo por factor de iteración.

Hallazgos Técnicos de la Auditoría

  • Fuga Crítica de Credenciales: El endpoint /users expone públicamente la base de datos de usuarios y hashes sin exigir token de acceso previo.
  • Robustez en Factor de Trabajo: El uso de 29,000 rondas en PBKDF2 previene la resolución expedita mediante diccionarios genéricos en equipos de propósito general.
  • Políticas Estrictas de Métodos HTTP: El backend fuerza el uso de verbos exactos (POST / GET) en rutas como /secret, provocando excepciones no controladas cuando se recibe un método no contemplado.
