Actividad 15: Análisis Forense y Eliminación de Metadatos con ExifTool

Objetivo de la actividad

Analizar e interpretar los metadatos incrustados en documentos ofimáticos e imágenes digitales utilizando la herramienta ExifTool para identificar autoría, marcas temporales, parámetros técnicos de captura y geolocalización GPS, así como ejecutar el proceso de sanitización y borrado seguro de metadatos.

Parte I. Análisis de metadatos del fichero WOA database application form.docx

1. ¿Cómo categorizó el archivo INTERPOL?

InterpolClassification: Unclassified (No clasificado).

2. ¿Qué template (plantilla) fue utilizado para la elaboración del archivo por parte de INTERPOL?

Template: G03 Basic Doc SP.dotx.

3. ¿Cuál fue el tiempo total de edición del fichero?

Total Edit Time: 45 minutes

4. Identifique la Compañía propietaria del fichero.

Company: OIPC - INTERPOL.

5. ¿Quién realizó la última modificación del fichero?

Last Modified By: Carolyn Lejeune.

6. ¿Cuál fue la fecha de creación del fichero en investigación?

Create Date: 2019:05:03 15:35:00Z.

Modify Date: 2019:05:03 16:22:00Z.

7. De acuerdo al análisis de metadatos del fichero de INTERPOL, identifique el creador del mismo.

Creator: Carolyn Lejeune.

Parte II. Análisis de metadatos del fichero XiaomiMiA2Lite.jpg

1. ¿Cuál fue la apertura / ISO utilizada?

ISO: 100

2. ¿Cuál es la longitud focal de la cámara con la que fue capturada la imagen?

Focal Length: 3.8 mm.

3. Señale si se utilizó la captura con Flash para obtener la imagen.

Flash: Off.

4. Señale la fecha de creación del archivo.

Create Date / Date/Time Original: 2020:05:28 18:11:41.

File Creation Date/Time: 2020:12:27 08:20:12.

5. Identifique los datos de ubicación GPS y señale el lugar exacto dónde la fotografía fue tomada.

  • GPS Latitude: 51 deg 15' 12.99" N
  • GPS Longitude: 0 deg 32' 21.93" W
  • GPS Position: 51 deg 15' 12.99" N, 0 deg 32' 21.93" W
  • GPS Altitude: 96.7 m Below Sea Level
  • GPS Date/Time: 2020:05:28 17:11:42Z

6. Elimine todos los metadatos de la muestra que se analiza.

Se ejecutó el comando para eliminar todas las etiquetas EXIF/GPS del archivo de muestra:

exiftool.exe -all= "infocrim\XiaomiMiA2Lite.jpg"

Este comando remueve la totalidad de los metadatos incrustados, mostrando la confirmación 1 image files updated y generando automáticamente un respaldo del archivo original (XiaomiMiA2Lite.jpg_original).
